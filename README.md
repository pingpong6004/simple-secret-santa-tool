# A Simple Secret Santa Tool
This is a very simple Secret Santa (german: Wichteln) tool, which let's you roll gifting pairs and generate links to send to your friends. The partners are encrypted on roll and decrypted locally on the recipent device, so nothing is saved and no backend is required.

# How To Use
## Step 1: Admin Mode
1. Enter the website
2. Add all participants names
3. Click on the roll button
4. Send each link to the corresponding participant (do not peek!)

## Step 2: User Mode
1. The recipient taps on the link
2. They the show button
3. Their chosen partner appears

**NOTE**: Due to the enrcyption, the links are very long and look quite menacing. You have to ensure your friends trust you enough to tap on a weir-looking, long link.
